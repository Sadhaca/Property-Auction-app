# Monetization Roadmap

## Phase 1 - Free (MVP Launch)
- Free registration and access
- Basic search and filters
- Property listings and detail pages
- Save up to 5 properties
- 1 saved search
- Goal: Build user base and data coverage

## Phase 2 - Freemium (Month 3-6)

### Free Tier
- 10 property views/day
- Basic filters
- 5 saved properties
- 1 saved search, no alerts

### Pro Plan - ₹499/month
- Unlimited property views
- All advanced filters
- Unlimited saved properties
- 10 saved searches with daily alerts
- Export to Excel (100 records/month)
- Priority new listing notifications

### Enterprise Plan - ₹2,999/month
- Everything in Pro
- API access (1000 calls/day)
- Unlimited exports
- Bulk download
- Custom alerts (instant notifications)
- Dedicated support

## Phase 3 - Premium Features (Month 6-12)
- Lead marketplace (connect buyers with auction advisors)
- City heatmaps and auction trend analytics
- Reserve price benchmarking and history
- Investment opportunity scoring
- Broker dashboard add-on
- White-label API for portals
- Custom reports

## Revenue Projections (Conservative)
- Month 6: 5,000 users, 2% conversion = 100 paid users = ₹50K MRR
- Month 12: 25,000 users, 3% conversion = 750 paid users = ₹3.75L MRR
- Month 18: 100,000 users, 4% conversion = 4,000 paid users = ₹20L MRR
